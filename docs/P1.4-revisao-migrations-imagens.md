> **Nota sobre B7:** A migration original tinha `SECURITY DEFINER` sem check interno de admin. Como `SECURITY DEFINER` com owner `postgres` (superuser) **bypassa RLS**, qualquer authenticated poderia chamar a RPC. Correção aplicada: adicionado `IF NOT public.is_admin() THEN RAISE EXCEPTION` no início da função.

> **Nota sobre STABLE vs VOLATILE:** A RPC `produto_imagem_definir_principal` originalmente era marcada como STABLE, mas modifica dados (UPDATE statements). STABLE é incorreto para funções mutadoras — o planner pode cachear resultados. Corrigido para VOLATILE.
