### 3. `20261011000001_produto_imagem_unique_principal.sql`
**Classificação: NÃO APROVÁVEL — correções críticas necessárias**

**Dois bloqueadores:**

**Bloqueio 1 — Bypass de autorização na RPC (Crítico)**
A função `produto_imagem_definir_principal` é `SECURITY DEFINER` com owner `postgres` (superuser). Isso significa que **todos os comandos `UPDATE` dentro da função bypassam RLS**. O comentário nas linhas 63-68 da migration é **incorreto** — afirma que RLS aplica dentro da função, mas isso não é verdade para SECURITY DEFINER com superuser.

**Correção necessária:**
```sql
CREATE OR REPLACE FUNCTION produto_imagem_definir_principal(
    p_produto_id bigint,
    p_imagem_id bigint
) RETURNS void AS $$
BEGIN
    -- AUTHORIZATION CHECK — crítico com SECURITY DEFINER
    IF NOT public.is_admin() THEN
        RAISE EXCEPTION 'Acesso negado: apenas administradores podem definir imagem principal'
            USING ERRCODE = 'P0804';
    END IF;

    UPDATE produto_imagem
    SET principal = false
    WHERE produto_id = p_produto_id
      AND principal = true;

    UPDATE produto_imagem
    SET principal = true
    WHERE id = p_imagem_id
      AND produto_id = p_produto_id;

    -- Validar que a imagem foi realmente atualizada
    IF NOT FOUND THEN
        RAISE EXCEPTION 'Imagem % não pertence ao produto %'
            USING ERRCODE = 'P0804',
            HINT = 'p_imagem_id does not belong to p_produto_id';
    END IF;
END;
$$ LANGUAGE plpgsql
   SECURITY DEFINER
   STABLE
   SET search_path = 'public', 'pg_catalog';
```

**Bloqueio 2 — Dados existentes quebram o índice único (Crítico)**
Produto 1 tem 2 imagens com `principal=true`. O `CREATE UNIQUE INDEX` falhará.

**Correção necessária — adicionar antes do CREATE INDEX:**
```sql
-- Correção de dados: manter apenas uma imagem principal por produto
-- Mantém a imagem com menor id como principal, desmarca as demais
UPDATE produto_imagem pi1
SET principal = false
WHERE pi1.principal = true
  AND pi1.id > (
    SELECT MIN(pi2.id)
    FROM produto_imagem pi2
    WHERE pi2.produto_id = pi1.produto_id
      AND pi2.principal = true
  );
```
